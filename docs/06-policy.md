# 06. 정책서

> ⚠️ 표시는 **제안값**이다. 코치 인터뷰·법률 검토 후 확정한다. 확정 전에는 랜딩·화면 문구에 수치를 쓰지 않는다.

## 1. 권한

### 1-1. 역할

Looproom은 **댄스팀이 서로 피드백하는 도구**다. 코치는 필수가 아니며, 있다면 팀의 한 역할로 참여한다.

| 역할 | 누구 | 한 줄 정의 |
|---|---|---|
| **Owner** | 팀 공간을 만든 사람 (보통 리더) | 모든 권한 + 결제 |
| **Leader** | 팀 운영진 | 프로젝트·멤버 관리, 노트 정리(해결·숨김), 팀 리포트 발송 |
| **Coach** | 전속·외부 코치, 안무가 | 멤버 권한 + 노트에 `Coach` 표시, 팀 리포트 발송 |
| **Member** | 팀원 | 프로젝트 영상 보기·올리기, **노트·스케치·멘션·👍**, 자기 리캡 |
| **Guest** | 학부모·심사위원 | 공유 링크 범위만 읽기 |

### 1-2. 공개 범위

| 범위 | 볼 수 있는 사람 | 용도 |
|---|---|---|
| **Team** (기본) | 그 프로젝트에 초대된 모든 사람 | 런스루, 파트 연습, 서로 피드백 |
| **Private take** | 올린 사람 + Leader·Coach | 개인 레슨, 아직 공개하기 싫은 연습 |

### 1-3. 권한 표

|---|---|---|---|---|---|
| 팀 공간 설정·삭제 | ✓ | — | — | — | — |
| 결제·플랜 | ✓ | — | — | — | — |
| 멤버 초대 | ✓ | ✓ | ✓ | 설정 허용 시 | — |
| 역할 변경·멤버 제거 | ✓ | ✓ | — | — | — |
| 프로젝트 생성·수정·보관 | ✓ | ✓ | ✓ | — | — |
| 과제(제출 요청) 생성 | ✓ | ✓ | ✓ | — | — |
| 영상 업로드 | ✓ | ✓ | ✓ | ✓ | — |
| 영상 보기 (Team 범위) | ✓ | ✓ | ✓ | ✓ | 공유된 것만 |

| 영상 삭제 | ✓ | ✓ | — | 자기 것 | — |
| **노트·스케치·멘션 작성** | ✓ | ✓ | ✓ | **✓** | — |
| 👍 동의 · 답글 | ✓ | ✓ | ✓ | ✓ | — |

| 데이터 내보내기 | 전체 | — | — | 자기 데이터 | — |

**절대 규칙**
1. 멤버는 **초대받은 프로젝트의 Team 범위 영상만** 볼 수 있다. 다른 프로젝트, 다른 사람의 Private take는 볼 수 없다.
2. 권한은 **DB 행 단위(RLS)** 에서 강제한다. 화면에서 숨기는 것만으로 막지 않는다.
3. AI 입력도 같은 권한 필터를 통과한 데이터만 쓴다. 리캡에는 **그 사람이 볼 수 있는 노트만** 들어간다.
4. @멘션 대상은 **그 프로젝트에 초대된 사람**으로 제한한다.

### 1-4. 동료 피드백 가이드

| 장치 | 동작 |
|---|---|
| 순간에 대해 쓰기 | 노트는 영상의 시점에 붙고, 작성기 안내 문구는 "What should change at this moment?" |
| 👍 동의 | 같은 말을 반복하지 않고 동의 표시. AI 리캡은 동의가 많은 노트를 먼저 보여줌 |
| Coach 표시 | Coach 역할의 노트에는 `Coach` 배지 |
| 숨기기 | Leader·Coach가 부적절하거나 중복된 노트를 숨김 (작성자에게는 사유와 함께 보임) |
| 해결 | 쓴 사람이 해결하거나, Leader·Coach가 해결. 멘션된 사람은 Practicing까지 |

- 멤버는 항상 무료. 비용은 팀 공간(Owner)이 낸다.

## 3. 데이터·개인정보

### 3-1. 기본 원칙

1. **비공개가 기본**: 모든 영상은 워크스페이스 멤버 중 권한 있는 사람만.
2. **내 데이터는 내 것**: 언제든 내보내기·삭제. 내보내기를 막아 붙잡지 않는다.
3. **최소 수집**: 댄서는 이름만으로 시작. 이메일·생년은 필요할 때만.
4. **목적 외 사용 금지**: 광고·데이터 판매 없음.

### 3-2. 보관·삭제 ⚠️

| 데이터 | 기본 보관 | 삭제 요청 시 |
|---|---|---|
| 영상 원본·변환본 | 워크스페이스 활성 동안 | 즉시 재생 불가, 30일 내 저장소 삭제 |
| 노트·스케치·답글 | 영상과 동일 | 영상과 함께 삭제 (리포트 인용도 제거) |
| 연습 로그 | 24개월 → 이후 집계값만 | 즉시 |
| AI 리포트 | 워크스페이스 활성 동안 | 즉시 |
| 동작 분석 결과 (Beta) | 12개월 | 즉시 |
| 백업 | 30일 순환 | 30일 내 자연 소멸 |
| 비활성 Free 워크스페이스 | 12개월 미접속 시 메일 2회 안내 후 30일 뒤 삭제 | — |

워크스페이스 설정에서 보관 기간을 줄일 수 있다 (예: 시즌 종료 후 90일).

### 3-3. 미성년자 ⚠️

| 지역 | 보호자 동의가 필요한 나이 |
|---|---|
| 미국 (COPPA) | 13세 미만 |
| EU (GDPR) | 국가별 13–16세 미만 |
| 한국 | 14세 미만 |
| 기타 | 해당 국가 기준, 불명확하면 16세 미만 |

- 가입 시 생년(월) 입력 → 기준 미만이면 **보호자 이메일 동의** 전까지 영상 업로드 불가 (과제 설명 보기만).
- 미성년자 영상은 게스트 공유 링크를 만들 수 없다 (보호자 대상 리포트 제외).
- 동작 분석(Beta)은 미성년자에게 **보호자 별도 동의** 필요.
- 보호자는 언제든 동의 철회·데이터 삭제 요청 가능.

### 3-4. 보안

- 전송 TLS, 저장 암호화, 영상은 비공개 버킷 + **만료되는 서명 재생 URL**.
- 다운로드 버튼 없음 (원본 다운로드는 업로더·Owner만).
- 관리자(운영자) 열람은 고객 요청 지원 시에만, 감사 로그 기록.

## 4. AI 정책

| # | 정책 |
|---|---|
| 1 | AI는 **사람이 쓴 노트만 요약**한다. 춤을 직접 평가하거나 점수를 매기지 않는다. |
| 2 | 모든 문장은 **출처 노트를 인용**하고, 근거 없는 문장은 서버에서 제거한다. |
| 3 | 코치가 보내는 리포트는 **코치 검토 후 발송**이 기본이다. 자동 발송은 코치가 직접 켤 때만. |
| 4 | AI 결과물에는 항상 **"AI summary"** 표시와 AI 전용 색(그라데이션)을 쓴다. |
| 5 | 고객 영상·노트를 **AI 학습에 쓰지 않는다.** 예외는 워크스페이스 Owner의 **명시적 옵트인**뿐이며, 기본은 꺼져 있다. 미성년자 데이터는 옵트인과 상관없이 제외한다. |
| 6 | 외부 LLM 제공사는 **입력 데이터를 학습에 쓰지 않는 계약 조건**으로만 사용한다. |
| 7 | 사용자는 문장 단위로 오류를 신고할 수 있고, 신고된 리포트는 다시 생성할 수 있다. |
| 8 | 동작 분석(Beta)은 워크스페이스 옵트인 + (미성년자) 보호자 동의가 있을 때만 실행하며, 결과는 본인의 이전 버전과의 비교로만 보여준다. |

## 6. 콘텐츠·음악 저작권

- 연습 영상에는 상업 음원이 포함될 수 있다. Looproom은 **비공개 코칭 목적**의 사용을 전제로 하고, 공개 배포 기능을 두지 않는다.
- 게스트 공유 시 **음소거 재생** 옵션을 기본 제안한다.
- 저작권 신고 접수 창구(DMCA 등)를 운영하고, 신고된 콘텐츠는 공유 링크를 먼저 차단한다.
- 부적절 콘텐츠 신고 → 운영자 검토 → 삭제·계정 조치.
